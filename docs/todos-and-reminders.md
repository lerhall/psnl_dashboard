# To-do vs reminders

Two lists that look alike but answer different questions.

| | To-do | Reminders |
| --- | --- | --- |
| Question it answers | *What do I need to do, and by when?* | *What must I not forget?* |
| Sorted by | Due date (soonest first) | Importance (crucial first) |
| Example | "Return library books", due Fri | "Renew railcard before Jan" (Crucial), "Ask Sam about the flat" (Low) |

If it has a real deadline, it's a **to-do**. If it's a nagging thought or a
"someday, but don't forget", it's a **reminder**.

## Importance levels

| Level | Meaning |
| --- | --- |
| 5 · Crucial | Real consequences if missed (money, legal, health, deadlines with penalties) |
| 4 · High | Should happen this week |
| 3 · Medium | Default. Should happen, no rush |
| 2 · Low | Nice to do |
| 1 · Unimportant | Ideas / maybes; review occasionally and delete freely |

Use the − / + buttons on the Reminders page to re-rank without retyping.

## Weekly review (5 minutes, Sunday)

1. Clear completed to-dos ("Clear completed" button).
2. Anything overdue: do it, re-date it, or delete it.
3. Skim reminders: promote what's become urgent, delete what no longer matters.
4. Move anything with a real date from reminders into to-dos.
